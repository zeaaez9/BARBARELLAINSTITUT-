Notifications SMS Optionnel

Mode actuel : sans SMS auto. Les confirmations passent par WhatsApp (liens en bas de page) et l’Espace Pro. Le SMS reste disponible plus tard (Twilio, OVH, SMS Partner…) si besoin — laissez « Démo » pour l’instant.

Twilio bloque les appels directs depuis le navigateur (CORS + sécurité des tokens). Indiquez un proxy serveur qui relaie vers l’API Twilio, ou laissez vide pour journaliser le payload prêt à envoyer. Format attendu côté proxy : POST JSON {to, body, from, accountSid}.

Stripe · Paiement acomptes

Suggestion 1 & 2 : config Dashboard + paiement carte à la réservation. La clé secrète ne doit jamais être dans le site — utilisez un proxy serveur (Netlify Function, Cloudflare Worker, PHP…).

Deux modes de test :
① http://localhost:8888/.netlify/functions/create-checkout — avec netlify dev + Stripe CLI
② https://TON-SITE.netlify.app/.netlify/functions/create-checkout — site local branché sur les fonctions déjà en ligne

Webhook Stripe
URL à enregistrer dans Stripe → Developers → Webhooks :
https://TON-SITE.netlify.app/.netlify/functions/stripe-webhook
Événements : checkout.session.completed, checkout.session.expired, payment_intent.payment_failed
Puis ajouter STRIPE_WEBHOOK_SECRET (whsec_…) dans Netlify Environment variables.
